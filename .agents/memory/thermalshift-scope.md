description: User-stated guardrails for ThermalShift data claims, evidence, and equipment control.

Keep ThermalShift as the existing hackathon dashboard; do not replace it with a generic landing page. Do not represent synthetic or unverified user-uploaded data as live or verified, claim real-world climate savings, fabricate blockchain activity, or connect physical refrigeration equipment.

Defer blockchain/testnet integration until scientific validation determines which results are credible enough to anchor. Until then, keep hashes local and describe their limited scope.

**Why:** the user asked for these constraints and explicitly placed scientific validation before on-chain anchoring.

**How to apply:** Keep reporting results as model outputs with visible data and model limitations. Any real data source or equipment integration would need an explicit request and truthful status labeling; do not add testnet writes before validation.
