---
name: ThermalShift scope
description: User-stated guardrails for ThermalShift data claims, evidence, and equipment control.
---

Keep ThermalShift as the existing hackathon dashboard; do not replace it with a generic landing page. Do not represent synthetic or unverified user-uploaded data as live or verified, claim real-world climate savings, fabricate blockchain activity, or connect physical refrigeration equipment.

**Why:** the user asked for these constraints.

**How to apply:** Keep reporting results as model outputs with visible data and model limitations. Any real data source, on-chain transaction, or equipment integration would need an explicit request and truthful status labeling.
